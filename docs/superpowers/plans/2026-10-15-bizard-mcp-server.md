# Bizard MCP Full-Lifecycle Server — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Bizard MCP server (`@openbiox/bizard-mcp`) covering the full user lifecycle (查询/使用/参考/贡献) with dual deployment (local stdio + hosted Streamable HTTP), a CI-generated content bundle, and reliable tests — per spec `docs/superpowers/specs/2026-10-15-bizard-mcp-design.md`.

**Architecture:** One TypeScript package (`mcp/` in-repo, later published as `@openbiox/bizard-mcp`) with a transport-agnostic core layer, stdio and Streamable HTTP entries, consuming a versioned content bundle generated by a Python CI script that reuses `generate_skills.py` extractors. Contribution tools degrade by environment: gh CLI → GITHUB_TOKEN → draft+deep-link.

**Tech Stack:** TypeScript ≥ 5.x on Node ≥ 20 (LTS; local dev machine has Node 25), official `@modelcontextprotocol/sdk`, Vitest, Python 3.11 + pytest for the bundle builder.

**Spec:** `docs/superpowers/specs/2026-10-15-bizard-mcp-design.md`

## Global Constraints

- Node ≥ 20, ESM modules (`"type": "module"`).
- stdio transport must never write logs to stdout; all diagnostics → stderr.
- Server never executes plotting code; it returns code + guidance only.
- Server never collects telemetry; the only write is the local anonymous JSONL usage log (opt-out via `BIZARD_USAGE_LOG=off`), no network reporting.
- Server holds no GitHub credentials of its own; contribution auth comes only from the user's environment (gh CLI → `GITHUB_TOKEN` → draft mode).
- Tool names: `bizard_search`, `bizard_list_categories`, `bizard_get_tutorial`, `bizard_get_code`, `bizard_adapt_guidance`, `bizard_cite`, `bizard_contribute_check`, `bizard_contribute_submit`.
- License string: `CC-BY-NC-4.0`; citation DOI: `10.1002/imm3.70038`.
- User free text in issue bodies truncated at 4000 chars per field, with truncation noted.
- Search returns structured suggestions (top-3 same-Level1) on zero hits, never a bare empty array.
- Update notice appended at most once per session per bundle version.
- Python scripts live in `.github/scripts/` and reuse `generate_skills.py` extractors via import (no copy-paste).
- Test coverage ≥ 80% (Vitest).
- Package lives in `mcp/` directory; CI bundle output goes to `files/mcp/bundle.json` + `files/mcp/llms.txt`.

## Review Focus

1. **Bundle CSV drift:** `gallery_data.csv` has commas inside quoted Description fields — naive split corrupts rows. Test: parse full 798-row CSV, assert row count and a description containing a comma round-trips.
2. **Zero-hit search on Chinese input with no zh content:** user searches zh, tutorial has no `nameZh`. Expect: result falls back to English fields, `nameZh` present but null, no crash.
3. **Contributor free-text injection into issue body:** a body containing `#` headings, backticks, or 10k-char text. Expect: valid issue body, truncation marker present, no raw crash.
4. **Bundle snapshot missing in npm package (fresh clone without CI):** `files/mcp/bundle.json` absent. Expect: server starts, tools return structured error pointing to snapshot/CI, never an unhandled throw.
5. **gh CLI not installed vs not authenticated:** `gh --version` succeeds but `gh auth status` fails → must degrade to level 2/3 with reason, not treat as authenticated.

```python
# .github/scripts/bundle_lib.py
"""Shared extraction helpers for the MCP content bundle.

Reuses code-block/package extractors from generate_skills.py so the two
scripts stay in lockstep (spec §10: extract functions shared via import,
never copied).
"""
from __future__ import annotations

import re
from pathlib import Path
from typing import List

from generate_skills import (
    CODE_BLOCK_RE,
    extract_all_code_blocks,
    extract_packages,
)

DATA_URL_RE = re.compile(r'https?://[^\s"\'\)]+\.(?:csv|tsv|rds|txt|xlsx?)(?=[\s"\'\)]|$)', re.IGNORECASE)


def extract_chart_id(qmd_path: Path) -> str:
    """Chart id is the QMD filename stem (matches gallery_data.csv Name↔file convention)."""
    return qmd_path.stem


def extract_data_urls(code: str) -> List[str]:
    """Find example-data URLs (csv/tsv/rds/txt/xlsx) referenced in code."""
    return [m.group(0).rstrip(".,;") for m in DATA_URL_RE.finditer(code)]


def _category_dir(qmd_path: Path) -> str:
    return qmd_path.parent.name


def _tutorial_url(qmd_path: Path, base_url: str) -> str:
    category = _category_dir(qmd_path)
    stem = qmd_path.stem
    return f"{base_url.rstrip('/')}/{category}/{stem}.html"


def extract_code_snippets(qmd_path: Path, chart_id: str, base_url: str) -> List[dict]:
    """Extract runnable code snippets per language from a tutorial QMD.

    Excludes setup/package blocks (same filter as extract_all_code_blocks).
    Each snippet carries its language, detected packages, and any example
    data URLs found in the code.
    """
    content = qmd_path.read_text(encoding="utf-8")
    tutorial_url = _tutorial_url(qmd_path, base_url)
    snippets: List[dict] = []
    for lang in ("r", "python", "julia"):
        blocks = extract_all_code_blocks(content, lang)
        if not blocks:
            continue
        packages = extract_packages(content, lang)
        for code in blocks:
            snippets.append({
                "chartId": chart_id,
                "lang": lang,
                "code": code,
                "packages": packages,
                "dataUrls": extract_data_urls(code),
                "sourceAnchor": tutorial_url,
            })
    return snippets
```

```python
# .github/scripts/build-bundle.py
#!/usr/bin/env python3
"""Build the MCP content bundle (bundle.json + llms.txt) from gallery CSVs,
recommender keywords, and tutorial QMDs.

Data-source-of-truth contract (spec §3.4): gallery CSV + QMD code + keywords
→ one versioned JSON bundle, published via the site and snapshotted into the
npm package. Must run AFTER sync-gallery.py in CI.
"""
from __future__ import annotations

import argparse
import csv
import json
import re
from datetime import datetime, timezone
from pathlib import Path
from typing import Dict, List, Optional

from bundle_lib import extract_code_snippets

CATEGORY_NAMES_ZH = {
    "Distribution": "分布", "Correlation": "相关", "Ranking": "排序",
    "Composition": "组成", "Proportion": "比例", "DataOverTime": "时间序列",
    "Animation": "动画", "Omics": "组学", "Clinics": "临床", "Hiplot": "Hiplot",
    "Python": "Python", "Julia": "Julia",
}

CITATION = {
    "paperDoi": "10.1002/imm3.70038",
    "paperUrl": "https://arxiv.org/abs/2503.06845",
    "bibtex": (
        "@article{wang2025bizard,\n"
        "  title={Bizard: an Open Atlas of Biomedical Data Visualization},\n"
        "  author={Wang, Shixiang and others},\n"
        "  journal={iMetaMed},\n"
        "  year={2025},\n"
        "  doi={10.1002/imm3.70038}\n"
        "}"
    ),
    "license": "CC-BY-NC-4.0",
}


def read_gallery_csv(path: Optional[Path]) -> Dict[str, dict]:
    """Parse gallery CSV into {Id: row}. csv module handles quoted commas."""
    if path is None or not path.exists():
        return {}
    with open(path, newline="", encoding="utf-8") as f:
        return {row["Id"]: row for row in csv.DictReader(f)}


def build_bundle(gallery_csv: Optional[Path], gallery_zh_csv: Optional[Path],
                 keywords_en: Optional[Path], keywords_zh: Optional[Path],
                 qmd_root: Path, base_url: str) -> dict:
    en_rows = read_gallery_csv(gallery_csv)
    zh_rows = read_gallery_csv(gallery_zh_csv)

    charts: List[dict] = []
    snippets: List[dict] = []
    for chart_id, row in en_rows.items():
        zh = zh_rows.get(chart_id)
        qmd_path = find_qmd(qmd_root, chart_id)
        code_refs = []
        if qmd_path is not None:
            snippets.extend(extract_code_snippets(qmd_path, chart_id, base_url))
            code_refs = sorted({s["lang"] for s in snippets if s["chartId"] == chart_id})
        charts.append({
            "id": chart_id,
            "name": row["Name"],
            "nameZh": zh["Name"] if zh else None,
            "type": row["Type"],
            "level1": row["Level1"],
            "level2": row["Level2"],
            "tutorialUrl": row["Tutorial_url"],
            "tutorialUrlZh": zh["Tutorial_url"] if zh else None,
            "imageUrl": row["Image_url"],
            "description": row["Description"],
            "codeRefs": code_refs,
        })

    categories = []
    for name in sorted({c["level2"] for c in charts}):
        categories.append({
            "name": name,
            "nameZh": CATEGORY_NAMES_ZH.get(name),
            "count": sum(1 for c in charts if c["level2"] == name),
        })

    keywords = None
    if keywords_en is not None and keywords_en.exists():
        keywords = json.loads(keywords_en.read_text(encoding="utf-8"))
    if keywords is None and keywords_zh is not None and keywords_zh.exists():
        keywords = json.loads(keywords_zh.read_text(encoding="utf-8"))

    return {
        "meta": {
            "siteVersion": "",
            "bundleVersion": 1,
            "generatedAt": datetime.now(timezone.utc).isoformat(),
            "license": "CC-BY-NC-4.0",
        },
        "categories": categories,
        "charts": charts,
        "codeSnippets": snippets,
        "keywords": keywords,
        "citation": CITATION,
    }


def find_qmd(qmd_root: Path, chart_id: str) -> Optional[Path]:
    matches = list(qmd_root.glob(f"*/{chart_id}.qmd"))
    return matches[0] if matches else None


def llms_txt(bundle: dict) -> str:
    lines = [
        "# Bizard",
        "",
        "> An open atlas of biomedical data visualization tutorials (R/Python/Julia).",
        f"> License: {bundle['citation']['license']}. Paper: {bundle['citation']['paperUrl']}",
        "",
    ]
    for cat in bundle["categories"]:
        lines.append(f"## {cat['name']}" + (f" ({cat['nameZh']})" if cat["nameZh"] else ""))
        for c in bundle["charts"]:
            if c["level2"] == cat["name"]:
                lines.append(f"- [{c['name']}]({c['tutorialUrl']})")
        lines.append("")
    return "\n".join(lines)


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--out", default="files/mcp", help="Output directory")
    parser.add_argument("--base-url", default="https://openbiox.github.io/Bizard/")
    parser.add_argument("--gallery", default="files/gallery_data.csv")
    parser.add_argument("--gallery-zh", default="files/gallery_data_zh.csv")
    parser.add_argument("--keywords", default="files/recommender_keywords.json")
    parser.add_argument("--keywords-zh", default="files/recommender_keywords_zh.json")
    parser.add_argument("--qmd-root", default=".")
    args = parser.parse_args()

    bundle = build_bundle(
        Path(args.gallery), Path(args.gallery_zh),
        Path(args.keywords), Path(args.keywords_zh),
        Path(args.qmd_root), args.base_url,
    )
    out_dir = Path(args.out)
    out_dir.mkdir(parents=True, exist_ok=True)
    (out_dir / "bundle.json").write_text(
        json.dumps(bundle, ensure_ascii=False, indent=2), encoding="utf-8"
    )
    (out_dir / "llms.txt").write_text(llms_txt(bundle), encoding="utf-8")
    print(f"✅ bundle: {len(bundle['charts'])} charts, "
          f"{len(bundle['codeSnippets'])} snippets → {out_dir}/bundle.json")


if __name__ == "__main__":
    main()
```

```typescript
import { readFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { dirname, join } from "node:path";
import type { Bundle } from "./types.js";

const SNAPSHOT_PATH = join(dirname(fileURLToPath(import.meta.url)), "snapshot", "bundle.json");

/**
 * Validate and load a bundle. Throws a descriptive error when the input
 * is not a bundle-shaped object — the server falls back to the snapshot
 * (or a startup failure) rather than serving garbage.
 */
export function loadBundle(inline: unknown): Bundle {
  const b = inline as Bundle | undefined;
  if (
    !b || typeof b !== "object" ||
    !Array.isArray(b.charts) || b.charts.length === 0 ||
    !b.charts.every((c) => typeof c?.id === "string" && c.id.length > 0) ||
    !Array.isArray(b.categories) ||
    !b.meta || typeof b.meta !== "object" ||
    !b.citation || typeof b.citation !== "object"
  ) {
    throw new Error("Bundle missing or invalid: expected object with non-empty charts[], categories[], meta, citation");
  }
  return b;
}

/** Read the npm-shipped snapshot; null when absent (fresh checkout without a build). */
export function loadSnapshot(): Bundle | null {
  try {
    return loadBundle(JSON.parse(readFileSync(SNAPSHOT_PATH, "utf-8")));
  } catch {
    return null;
  }
}
```

```typescript
import type { Bundle, Chart } from "./types.js";

export interface SearchHit {
  chart: Chart;
  score: number;
}

/** Tokenize a query into lowercase terms; CJK chars become individual terms. */
function tokenize(query: string): string[] {
  return query
    .toLowerCase()
    .split(/[\s,，。;；:、!！?？()（）]+/)
    .map((t) => t.trim())
    .filter((t) => t.length > 0);
}

/**
 * Expand query terms via the bundle's synonym table (both directions:
 * canonical → synonyms and synonyms → canonical) for cross-language reach.
 */
export function expandTerms(query: string, synonyms: Record<string, string[]>): string[] {
  const terms = new Set<string>();
  for (const raw of tokenize(query)) {
    terms.add(raw);
    for (const [canon, syns] of Object.entries(syns)) {
      const all = [canon, ...syns].map((s) => s.toLowerCase());
      if (all.includes(raw)) {
        for (const s of all) terms.add(s);
      }
    }
  }
  return [...terms];
}

/**
 * Score charts against expanded terms: name matches weigh most, then type,
 * then description/levels. Deterministic; no LLM.
 */
export function searchCharts(bundle: Bundle, query: string, opts?: { category?: string }): SearchHit[] {
  const terms = expandTerms(query, bundle.keywords?.synonyms ?? {});
  const hits: SearchHit[] = [];
  for (const chart of bundle.charts) {
    if (opts?.category && opts.category !== chart.level2) continue;
    let score = 0;
    for (const term of terms) {
      if (chart.name.toLowerCase().includes(term)) score += 5;
      if (chart.nameZh?.toLowerCase().includes(term)) score += 5;
      if (chart.type.toLowerCase().includes(term)) score += 3;
      if (chart.description.toLowerCase().includes(term)) score += 2;
      if (chart.level2.toLowerCase() === term) score += 3;
    }
    if (score > 0) hits.push({ chart, score });
  }
  return hits.sort((a, b) => b.score - a.score || a.chart.id.localeCompare(b.chart.id));
}

/** Zero-hit fallback: top-3 charts from the same Level1 category as best type guess. */
export function adjacentSuggestions(bundle: Bundle, query: string, limit = 3): Chart[] {
  const terms = expandTerms(query, bundle.keywords?.synonyms ?? {});
  const level1 = bundle.charts.find((c) =>
    terms.some((t) => c.level2.toLowerCase().includes(t) || c.type.toLowerCase().includes(t))
  )?.level1;
  if (!level1) return bundle.charts.slice(0, limit);
  return bundle.charts.filter((c) => c.level1 === level1).slice(0, limit);
}
```

```typescript
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";

export function searchTool(bundle: Bundle, query: string, language: "en" | "zh", category?: string, limit = 5) {
  const hits = searchCharts(bundle, query, { category });
  const nameOf = (c: Chart) => (language === "zh" ? c.nameZh ?? c.name : c.name);
  const cards = hits.slice(0, limit).map(({ chart }) => ({
    id: chart.id,
    name: nameOf(chart),
    type: chart.type,
    imageUrl: chart.imageUrl,
    tutorialUrl: language === "zh" ? (chart.tutorialUrlZh ?? chart.tutorialUrl) : chart.tutorialUrl,
    description: chart.description,
  }));
  if (cards.length > 0) return json(cards);
  const near = adjacentSuggestions(bundle, query).map((c) => ({ id: c.id, name: nameOf(c), tutorialUrl: language === "zh" ? c.tutorialUrlZh ?? c.tutorialUrl : c.tutorialUrl }));
  return json({ results: [], suggestions: near, note: "No exact matches. Nearby charts in the closest category:" });
}

function categoriesTool(bundle: Bundle) {
  return json(bundle.categories);
```

```typescript
import type { Bundle, Chart, CodeSnippet } from "./types.js";

export function findChart(bundle: Bundle, id: string): Chart | undefined {
  const lower = id.toLowerCase();
  return bundle.charts.find((c) => c.id.toLowerCase() === lower);
}

export function snippetsFor(bundle: Bundle, chartId: string): CodeSnippet[] {
  return bundle.codeSnippets.filter((s) => s.chartId === chartId);
}

export function tutorialPayload(bundle: Bundle, chartId: string) {
  const chart = findChart(bundle, chartId);
  if (!chart) throw new Error(`Unknown chartId: ${chartId}`);
  const snips = snippetsFor(bundle, chart.id);
  return {
    id: chart.id,
    name: chart.name,
    nameZh: chart.nameZh,
    description: chart.description,
    tutorialUrl: chart.tutorialUrl,
    tutorialUrlZh: chart.tutorialUrlZh,
    imageUrl: chart.imageUrl,
    packages: [...new Set(snippets.flatMap((s) => s.packages))],
    dataUrls: [...new Set(snippets.flatMap((s) => s.dataUrls))],
    languages: chart.codeRefs,
    snippetCount: snippets.length,
  };
}

export function codePayload(bundle: Bundle, chartId: string, language: "r" | "python" | "julia") {

      packages: [],
      dataUrls: [],

      message: `This tutorial has no structured ${language} code. Full tutorial: ${chart.tutorialUrl}`,

    };

  }

    code: snips.map((s) => s.code).join("\n\n"),
    packages: [...new Set(snips.flatMap((s) => s.packages))],
    dataUrls: [...new Set(snips.flatMap((s) => s.dataUrls))],
```

```typescript
import type { Bundle } from "./types.js";
import { findChart } from "./tutorial.js";

const METHODS_SENTENCE_EN =
  "The figure was generated following the Bizard tutorial \"{name}\" ({url}); Bizard is licensed CC-BY-NC-4.0.";
const METHODS_SENTENCE_ZH =
  "该图参考 Bizard 教程「{name}」({url}) 复现;Bizard 采用 CC-BY-NC-4.0 许可。";

export function citationPayload(
  bundle: Bundle, chartId: string | null, paperOnly: boolean, format: "bibtex" | "text" | "json",
): { text: string; json: unknown } {
  const cite = bundle.citation;
  const chart = chartId && !paperOnly ? findChart(bundle, chartId) : undefined;
  if (chartId && !paperOnly && !chart) throw new Error(`Unknown chartId: ${chartId}`);

  let text: string;
  if (format === "bibtex") {
    text = chart
      ? `${cite.bibtex}\n% Chart: ${chart.name} — ${chart.tutorialUrl}\n% License: ${cite.license}`
      : cite.bibtex;
  } else if (format === "text") {
    text = chart
      ? METHODS_SENTENCE_EN.replace("{name}", chart.name).replace("{url}", chart.tutorialUrl)
        + "\n" + METHODS_SENTENCE_ZH.replace("{name}", chart.name).replace("{url}", chart.tutorialUrl)
      : `Biomedical charts adapted from Bizard (${cite.paperUrl}), DOI ${cite.paperDoi}, license ${cite.license}.`;
  } else {
    return {
      text: "",
      json: {
        paper: { doi: cite.paperDoi, url: cite.paperUrl, license: cite.license },
        chart: chart ? { id: chart.id, name: chart.name, url: chart.tutorialUrl } : null,
      },
    };
  }
  return { text, json: null };
}
```

```typescript
// mcp/src/usage.ts
import { appendFile, mkdir } from "node:fs/promises";
import { createHash } from "node:crypto";
import { dirname, join } from "node:path";
import { homedir } from "node:os";

const DEFAULT_DIR = join(homedir(), ".cache", "bizard-mcp");

export interface UsageEvent {
  event: "search" | "view" | "adapt" | "cite";
  chartId?: string;
  language?: string;
  query?: string;
}

export async function recordUsage(
  ev: UsageEvent, logPath: string = defaultLogPath(),
): Promise<boolean> {
  const dest = process.env.BIZARD_USAGE_LOG === "off" ? null : process.env.BIZARD_USAGE_LOG ?? dest;
  if (process.env.BIZARD_USAGE_LOG === "off") return false;
  const target = dest ?? DEFAULT_LOG;
  const row = {
    ts: new Date().toISOString(),
    event: ev.event,
    chartId: ev.chartId ?? null,
    language: ev.language ?? null,
    queryHash: ev.query ? sha256_8(ev.query) : null,
  };
  await mkdir(dirname(target), { recursive: true });
  await appendFile(target, JSON.stringify(row) + "\n", "utf-8");
  return true;
}

export async function readUsage(limit = 100, logPath?: string): Promise<Array<Record<string, unknown>>> {
  if (process.env.BIZARD_USAGE_LOG === "off") return [];
  const file = logPath ?? DEFAULT_LOG;
  try {
    const txt = await import("node:fs/promises").then((m) => m.readFile(file, "utf-8"));
    return txt.trim().split("\n").filter(Boolean).slice(-limit).map((l) => JSON.parse(l));
  } catch {
    return [];
  }
}

const DEFAULT_LOG = join(homedir(), ".cache", "bizard-mcp", "usage-log.jsonl");
function logPath(override?: string): string {
  return process.env.BIZARD_USAGE_LOG && process.env.BIZARD_USAGE_LOG !== "off"
    ? process.env.BIZARD_USAGE_LOG
    : override ?? DEFAULT_LOG;
}
function sha256_8(s: string): string {
  return createHash("sha256").update(s).digest("hex").slice(0, 8);
}
```

```typescript
// mcp/src/http.ts
import { createServer } from "node:http";
import { StreamableHTTPServerTransport } from "@modelcontextprotocol/sdk/server/streamableHttp.js";
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";

const PORT_DEFAULT = 3000;
const RATE_CAPACITY = 60;        // requests/min per IP
const RATE_INTERVAL_MS = 60_000;

interface Bucket { tokens: number; last: number; }

export function startHttpServer(server: McpServer, port: number): void {
  const buckets = new Map<string, Bucket>();

  const http = createServer(async (req, res) => {
    const ip = req.socket.remoteAddress ?? "unknown";
    if (!allow(ip, buckets)) {
      res.writeHead(429, { "Retry-After": "30" });
      res.end(JSON.stringify({ error: "rate limited" }));
      return;
    }
    if (req.method === "POST" && req.url === "/mcp") {
      // One stateless transport per request (spec §6.2: public anonymous access)
      const transport = new StreamableHTTPServerTransport({ sessionIdGenerator: undefined });
      res.on("close", () => transport.close());
      await server.connect(transport);
      // The SDK server handles the POST body via the transport
      // Note: stateless mode — each POST gets a fresh transport.
      await handleBody(req, res, transport);
      return;
    }
    res.writeHead(404).end();
  });

  http.listen(port, () => console.error(`bizard-mcp HTTP listening on :${port} (Streamable HTTP, anonymous, rate-limited)`));
}

function allow(ip: string, buckets: Map<string, Bucket>): boolean {
  const now = Date.now();
  const b = buckets.get(ip) ?? { tokens: RATE_CAPACITY, last: now };
  const elapsed = now - b.last;
  b.tokens = Math.min(RATE_CAPACITY, b.tokens + (elapsed / RATE_INTERVAL_MS) * RATE_CAPACITY);
  b.last = now;
  if (b.tokens < 1) { buckets.set(ip, b); return false; }
  b.tokens -= 1;
  buckets.set(ip, b);
  return true;
}

async function handleBody(req: IncomingMessage, res: ServerResponse, transport: StreamableHTTPServerTransport): Promise<void> {
  const chunks: Buffer[] = [];
  for await (const chunk of req) chunks.push(chunk as Buffer);
  const body = JSON.parse(Buffer.concat(chunks).toString("utf-8") || "{}");
  await transport.handleRequest(req, res, body);
}
```
